# ShowMe 사진 이해와 물체 위치 검증 결과

2026년 11월 1일, 사용자 계정의 Meta Model API에서 `muse-spark-1.3`을 실제 호출했습니다. **사진 기반 설명·질문 대상 찾기·사각형 강조를 핵심 기능으로 개발할 수 있다는 초기 근거를 확보했습니다.** 위치 상자는 물체보다 넓게 잡힐 수 있으므로 담당자의 수정·승인 기능을 함께 구현합니다.

## 자료와 평가 방법

Wikimedia Commons의 CC0 실제 사진 3장을 사용했습니다. 직접 촬영하거나 이미지 생성으로 만든 자료는 아닙니다.

| 파일 | 장면 | 저작자와 출처 |
| --- | --- | --- |
| reception.jpg | 화면이 설치된 접수대 | ITCENTRELJN · [원본과 CC0 표기](https://commons.wikimedia.org/wiki/File:Reception_Desk.jpg) |
| desk.jpg | 노트북·필기구·메모지가 놓인 책상 | www.Pixel.la Free Stock Photos · [원본과 CC0 표기](https://commons.wikimedia.org/wiki/File:Desk-laptop-notebook-pen_(23958719819).jpg) |
| notepad.jpg | 노트북과 격자 노트·검은 펜 | Eric Bailey · [원본과 CC0 표기](https://commons.wikimedia.org/wiki/File:Laptop_picture_with_notepad.jpg) |

[출처 기록](photo-sources.json)에 다운로드 URL, 라이선스, 원본 해시를 기록했습니다. 원본 사진은 로컬 `inputs/`에 보관합니다.

응답을 보기 전 Codex가 사진을 확인하고 [질문·예상 상태·대략적인 위치](cases.json)를 작성했습니다. 질문 10개를 각각 한 번씩 호출했으며, 예상 상태와 위치는 모델에 전달하지 않았습니다. 모든 호출에 같은 지시문과 응답 구조를 사용했고 자동 재시도는 하지 않았습니다.

응답과 표시 이미지는 Codex가 대조했습니다. 독립적인 사람 검수나 사용자 작업 테스트는 수행하지 않았으므로 정식 정확도 벤치마크로 해석하지 않습니다.

## 실제 호출 결과

| 항목 | 관찰 결과 |
| --- | --- |
| 실제 API 호출 | 10건, 모두 HTTP 200 및 응답 구조 검사 통과 |
| 명확한 물체 질문 | 5건 모두 해당 대상과 위치 확인 |
| 사진에 없는 대상 | 3건 모두 보이지 않는다고 답변, 위치 생성 없음 |
| 모호한 질문 | 2건 모두 확인 질문 반환, 임의 위치 생성 없음 |
| 담당자 메모 반영 | 검은 펜의 ‘참가자 서명용’ 메모를 답변에 반영 |
| 응답 시간 | 평균 4.715초, 최소 2.666초, 최대 6.391초 |
| API 응답에 보고된 토큰 | 입력 22,426 · 출력 9,053 · 합계 31,479 |

토큰 수는 API 사용량 응답의 합계입니다. 실제 과금액이나 잔여 크레딧은 이 실험에서 조회하지 않았습니다.

| 질문 | 실제 동작 | 참고 위치와의 IoU |
| --- | --- | --- |
| 메모지 위 검은 펜 | 검은 펜 강조, 서명용 메모 반영 | 0.7012 |
| 접수대 뒤 큰 화면 | 벽면의 큰 화면 강조 | 0.8252 |
| 노트북 검은 키보드 | 키보드 영역 강조 | 0.9096 |
| 은색·초록색 볼펜 | 왼쪽 볼펜 강조 | 0.9356 |
| 오른쪽 위 형광펜 | 오른쪽 위 형광펜 강조 | 0.8793 |
| 영수증 프린터 | 보이지 않음 | 해당 없음 |
| 가위 | 보이지 않음 | 해당 없음 |
| 머그컵 | 보이지 않음 | 해당 없음 |
| 초록색 물건 하나 선택 요청 | 형광펜·메모지·탭 중 무엇인지 질문 | 해당 없음 |
| ‘이건 어디에 놓나요?’ | 펜·노트·노트북 중 무엇인지 질문 | 해당 없음 |

IoU는 Codex가 응답 전에 작성한 대략적인 사각형과의 겹침 비율입니다. 사람의 정밀 주석과 비교한 수치가 아닙니다. 5개 평균은 0.8502입니다.

## 확인된 제약과 구현 결정

- 검은 펜과 벽면 화면의 상자는 실제 물체보다 넓어 배경을 포함했습니다. 물체 위치를 안내하는 용도로 쓰고, 정확한 윤곽이나 치수로 취급하지 않습니다.
- 담당자가 강조 위치를 수정하고 안내서를 승인할 수 있게 합니다.
- 대상이 없는 응답과 확인이 필요한 응답에는 강조 상자를 표시하지 않습니다.
- 질문 응답이 평균 약 4.7초 걸렸으므로, 질의응답 화면에 진행 상태를 표시합니다. 안내서 생성 결과는 저장해 재사용합니다.
- 이번 검증은 단일 사진 질의응답입니다. 여러 단계의 안내서 생성, 여러 사진 간 근거 선택, 사용자가 누른 영역의 해석, 안내서 저장·공유는 아직 검증하지 않았습니다.
- 실제 행사 접수대 준비 절차나 사용자 작업 성공률은 아직 평가하지 않았습니다. 같은 공간의 작업 단계 사진과 사용자 테스트로 이어갑니다.
- SAM 3.1, 동영상, 실시간 촬영, 작업 완료 자동 판정은 호출·검증하지 않았습니다.

## 재현 자료와 다음 작업

단일 호출 도구는 [검증 안내](README.md)의 명령으로 실행합니다. 같은 사진을 다시 호출하면 추가 크레딧이 사용되며 응답은 달라질 수 있습니다.

로컬 `results/suite-index.json`에 10개 질문과 실행 폴더의 연결을 저장했습니다. 각 폴더에는 전송 이미지, 응답·사용량·시각, 위치 표시 이미지, 결과 HTML과 Codex 검토 기록이 있습니다. 로컬 `results/index.html`에서 전체 결과를 볼 수 있습니다. 원본 실행 기록의 사람 검토 상태는 대기로 유지했습니다.

다음 개발 순서는 사진·메모 입력 → 안내서 초안 생성 → 설명·강조 위치 수정과 승인 → 단계별 따라 하기와 근거 사진 질의응답입니다.

## 도구 검증

실제 호출 전 로컬 테스트 8개가 통과했습니다. 사진 회전 보정과 표시 이미지 일치, 잘못된 좌표·사진 ID·모호한 응답 차단, 키와 이미지 payload의 로그 제거, 정답의 요청 제외, API 오류 기록, 응답 성공과 검토 판정 분리를 확인했습니다. 이 테스트에서는 가짜 API 응답을 사용했으며 위 실제 호출 10건과 구분합니다.
