# R12 긴 대기 개선 — 추론 깊이와 교정 왕복

2026년 11월 2일. 기준 `3a51ee5`. [실행 전 계획](plan.json), [이전 지연의 구간별 기록](diagnosis.json), [기존 요청 본문 동등성](baseline-parity.json).

## 비교 대상

- `legacy`: R12 1차 그대로. 추론 깊이를 지정하지 않고 단순 외형만 검토 생략. 그 외 작은 판정 검토, 필요 시 전체 교정으로 최대 3회.
- `corrective`: 최초 해석과 별도 전체 교정 검토를 각각 명시적 `low`로 실행. 재검토가 완전한 최종 답변을 직접 반환해 세 번째 왕복이 없다. 새 단순 외형의 1회 경로를 유지하므로 제품은 1~2회다.

최초/전체 교정 프롬프트·응답 스키마·기존 근거 검사는 변경하지 않는다. 업무·선택·확인 대화·미해결 검토를 없애지 않는다. 사진/규칙도 제거하지 않는다. 출력 토큰을 강제로 자르거나 중간 초안을 반환하지 않는다. 공개 질문에서 내부 비교 정책을 선택할 수 없다.

## 절차

1. 이전 47.453초 요청을 최초 해석 29.573초·검토 17.880초로 나누고, 보고된 내부 추론 토큰과 최종 출력 토큰을 구분했다. 내부 추론 **내용**은 수집하지 않는다.
2. 같은 선택 질문에서 깊이를 지정하지 않음·최초만 low·검토만 low·둘 다 low를 순서대로 확인했다. 둘 다 low인 작은 검토 방식은 추가 교정 때문에 39.226초 걸려 폐기했다. 결과를 버리지 않고 보관한다.
3. 전체 교정을 두 번째 호출에 수행하는 방식으로 선택 질문·OR·미확인 조건 canary를 확인했다.
4. 고정 28개와 동일한 선택 질문 새 요청 3회를 기존/수정 각각 실행한다. seed 523으로 28개를 섞고 선후를 14개씩 교대한다. 선택 반복 3쌍을 덧붙인다. 동시 최대 2개, 재시도·응답 캐시·초안 공유 없음. 공급자 내부 캐시는 제어하지 않는다.

질문·규칙·사진·정답 해시는 R10·R11 당시와 같다. 이번에는 알려진 **회귀 세트**이며 새로운 독립/블라인드 평가가 아니다. 선택 반복은 같은 질문의 변동 확인이지 새 질문 3개가 아니다. 별도 미사용 평가 세트라고 부르지 않는다.

## 실행

```sh
python3 scripts/benchmark_reasoning.py --phase paired
python3 scripts/benchmark_reasoning.py --phase paired --execute
```

첫 명령은 계획만 확인한다. 실제 실행은 최대 155회(31쌍 × [기존 최대 3 + 수정 최대 2])다. 실제 수는 단순 외형 1회 경로와 교정 발생 여부에 따라 달라진다. canary 단계는 `canary`, `corrective-canary`이며 개발 기록이다. 실패·느린 사례·추가 교정을 임의 재시도/제외하지 않는다.

## 계측과 해석

각 요청은 payload 준비·HTTP 대기·응답 디코딩/스키마 검사 시간을 나눠 기록한다. HTTP 시간에는 직렬화·연결·네트워크·공급자 대기열·사진 처리·추론·출력 생성이 함께 포함된다. 공급자 내부 구간을 각각 직접 계측한 값은 아니다. 서비스 함수 전체 시간과 HTTP 합계 차이도 함께 보관한다.

Meta가 보고한 reasoning_tokens와 completion_tokens의 차이로 최종 출력 토큰을 계산한다. 사용량이 없는 실패는 청구 집계를 구성하지 못한다. 비용/잔액을 추정하지 않는다. 관련 공식 문서: [추론 설정](https://dev.meta.ai/docs/reasoning), [Chat Completions](https://dev.meta.ai/docs/protocols/chat-completions).

사전에 고른 목표는 새 실제 비교에서 중앙값과 P95 감소, 고정 품질 유지, 선택 질문 3회 각각 30초 이내다. 30초는 이번 검증 목표이지 보장된 상한이 아니다. 사용자 대기 수용성·새 사진·외부 검수는 별도로 남는다.

results에는 최종 서비스 응답과 비공개 내용이 없는 사용량/구간 지표·manifest·요약을 저장한다. 이미지 요청 payload·키·인증 헤더·내부 추론 원문은 저장하지 않는다. 실제 브라우저와 최종 판단은 [보고서](../../docs/R12_TAIL_RESULTS.md)에 기록한다.
