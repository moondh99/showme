# 고정 질문 평가 v1

이 폴더의 baseline은 당시 프롬프트와 답변 정책의 기록이다. 11월 2일 [비판 기반 개선](../../docs/IMPROVEMENT_RESULTS.md)에서 질문 목적과 승인 원문 응답 정책이 변경되었다. 현재 함수로 재실행한 결과는 당시 48회 결과와 동일 조건이 아니며, 이 수치를 현재 버전의 일반 정확도로 사용하지 않는다. 현재 직접 API 요청은 외형·위치 질문에 `intent=appearance`, 업무 규칙 질문에 `intent=procedure`를 지정한다.

2026년 11월 2일 정리. 20개 사례 × 2회, 2턴 대화 4개를 포함해 총 48회 실제 Muse Spark 호출. 실행 전에 cases.json과 contexts.json을 고정했고 baseline-manifest.json에 입력·프롬프트 해시를 보관합니다.

## 결과와 한계

- 응답 상태 일치 48/48, 구조·필수 문자열·해당 위치 검사 48/48.
- 근거 부족·대상 없음의 확답 0/16.
- 위치 기준이 있는 12회에서 IoU ≥ 0.5.
- 응답 시간 중앙값 4.689초, 최근접 순위 P95 7.273초. 서버 질문 처리 함수 기준입니다.
- 실제 공개 사진의 응답 20회, AI 연출 이미지 응답 28회.

이 결과를 ‘AI 정확도 100%’라고 부르지 않습니다. 알려진 사진을 재사용했고 기대 상태·문자열·기준 영역은 Codex가 작성했습니다. 일부 문구는 앞선 시연 질문과 같은 유형입니다. 문자열 검사는 답변의 의미 전체를 판정하지 않습니다. 데이터·출처·그림자 질문을 바꾼 독립 평가와 실제 사용자의 작업 효과는 별개입니다.

baseline-responses.jsonl에 원본 답변·사용량·자동 검사, baseline-manual-review.json에 내부 텍스트 검토 범위를 기록했습니다. 기준 사각형은 사람이 독립적으로 새로 라벨링한 정답이 아니라 기존 작성자 검토 영역입니다.

## 실행

프로젝트 루트에서 `python3 scripts/evaluate_answers.py`를 실행하면 입력 사진 해시와 예정 호출 수만 확인합니다. `--execute --repeat 2 --workers 2`를 붙이면 실제 API를 사용합니다. 최대 동시 요청 2개, 자동 재시도 없음. 공개 질문 API의 속도 제한을 바꾸는 방식이 아닌 별도 오프라인 평가 진입점입니다. 작성자 초안·기존 승인본·질문 테이블은 수정하지 않습니다.

실제 사진 원본은 experiments/meta-vision/photo-sources.json의 CC0 출처를 사용합니다. contexts.json에 지정한 로컬 파일과 정규화 해시가 맞아야 실행됩니다. 연출 이미지는 public/demo/reception-setup/에 포함돼 있습니다. API 키는 .env.local에서만 읽습니다.

요약 계산의 P95는 최근접 순위로 산출합니다. 초기 요약 계산의 순위 선택을 수정했으며 저장된 동일 응답에서 재계산했습니다. API를 다시 호출하거나 유리한 응답으로 교체하지 않았습니다.


R10·R11 이후 제품 기본 서비스는 `reasoning.answer_with_reasoning`이며 이 v1 실행기가 사용하는 `vision.answer_question`은 비교용 단일 호출 경로입니다. 현재 제품의 평가에는 [새 고정 세트](../r10-r11-v1/README.md)를 사용합니다.
