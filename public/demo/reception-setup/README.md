# ShowMe 행사 접수대 준비 데모 자료

이미지 4장은 내장 image_gen으로 만든 AI 연출 이미지입니다. 실제 행사 촬영 사진이나 실사용자 평가 자료가 아닙니다. 완성된 접수대와 각 영역의 참조 이미지이며 실제 작업 전후를 촬영한 연속 기록이 아닙니다. 실명·개인정보·행사 로고는 포함하지 않았습니다.

순서: 01-sign.png → 02-signing-tools.png → 03-badge-trays.png → 04-overview.png.

가상 시연 규칙: 검은 펜은 참가자 서명용, 파란 펜은 운영자 메모용. 파란 트레이는 사전등록, 노란 트레이는 현장등록 명찰용. 운영 규칙의 근거는 담당자 입력이며 이미지 색상만으로 용도를 추정하지 않습니다.

guide.json에 제목·목표·단계별 행동 메모·승인 문구·검토한 강조 위치·질문 예시가 있습니다. image-prompts.json은 최종 생성 프롬프트, photo-sources.json은 AI 자료 표기와 해시입니다. 서비스의 초안 생성·질문 답변은 실제 Meta API로 검증했습니다.

시연 대본: docs/DEMO_RUNBOOK.md. 영상 길이는 제안이며 공식 제출 요건은 별도 확인해야 합니다. 영상 촬영·외부 배포는 이 자료에 포함하지 않았습니다.
