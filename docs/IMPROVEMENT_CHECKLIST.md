# ShowMe 비판 기반 개선 목록

2026년 11월 2일 KST. 사용자가 요청한 악마의 변호인 평가를 개발 작업으로 옮긴 실행 기준이다. 체크는 구현·검증 근거가 생긴 뒤 갱신한다. 실제 사용자 효과와 미관찰 성과는 만들지 않는다.

## 목표

처음 보는 작업자가 사진에서 대상을 고르고 필요한 승인 규칙을 빠르게 찾게 한다. 사진 관찰·승인 원문·AI의 해석을 구별하고, 담당자의 작성·보완 부담을 낮춘다. 기존 승인본은 수정하지 않는다.

## P0 — 이번 개발 수정

- [x] **I01 · 신뢰 표현 바로잡기.** ‘근거를 확인한 답변’ 제거. 승인 원문을 제시하는 응답과 사진을 해석한 응답을 구분하고 대상 연결은 AI 해석임을 명시한다.
  - 완료 기준: UI가 의미 정확성의 자동 보장을 주장하지 않는다. 사진 관찰은 담당자 승인으로 표시하지 않는다.
- [x] **I02 · 인용과 반대되는 업무 지시 차단.** 승인 문구가 존재한다는 이유로 모델의 자유 답변까지 통과시키지 않는다. 업무 규칙 답변은 서버가 확인한 승인 원문을 그대로 구성한다.
  - 완료 기준: ‘파란 펜은 운영자용’ 인용 + ‘참가자 서명에 사용 가능’ 자유 답변 재현에서 반대 지시가 사용자 응답과 저장 기록에 남지 않는다. 잘못된 대상에 올바른 인용을 연결하는 문제는 남는 한계로 기록한다.
- [x] **I03 · 사진 질문과 업무 규칙 분리.** 선택했다고 사진 외형·위치 질문까지 승인 문구를 강제하지 않는다. 질문 목적을 명시적으로 전달하고 확인 대화에서도 유지한다.
  - 완료 기준: 선택 상태의 사진 관찰 응답은 허용되고, 같은 사진 근거만으로 용도·절차를 답하면 유보한다. 기존 클라이언트는 보수적 기본값으로 동작한다.
- [x] **I04 · 사진·물체 선택·질문을 핵심 화면에 통합.** 선택 버튼을 사진 위로 올리고 단계 설명·완료 제어보다 질문을 먼저 노출한다. 좁은 화면에서도 제목·단계 탐색이 사진을 과도하게 밀어내지 않게 한다.
  - 완료 기준: 데스크톱·모바일 크기에서 핵심 동선 확인. 사진 좌표·마스크 정렬 유지. 키보드·단계별 요청 격리 유지.
- [x] **I05 · 질문 입력 마찰 줄이기.** 선택 후 ‘용도·규칙’, ‘외형·위치’ 빠른 질문 제공. 사진 선택만으로 유료 질문 API를 자동 호출하지 않는다.
  - 완료 기준: 선택 → 빠른 질문 클릭 → 답변. 모델 처리 중에도 승인 설명과 단계 이동 사용 가능. 실패 시 질문·선택 보존.
- [x] **I06 · 작성 화면에서 좌표 입력 접기.** 숫자 좌표는 고급 설정으로 이동하고 사진 조작·행동 메모를 우선한다. 기술 좌표를 몰라도 기본 작성 가능하게 한다.
  - 완료 기준: 기본 화면에 좌표 숫자가 노출되지 않는다. 펼친 좌표 편집·영역 삭제·검토 해제·승인 고정 회귀 확인.
- [x] **I07 · 안내서 전체의 승인 문구 찾기.** 현재 단계에 정보가 없을 때 다른 단계의 승인 설명을 키워드로 찾고 이동하는 경로를 제공한다. 모델이 다른 단계 근거를 몰래 혼합하지 않는다.
  - 완료 기준: ‘명찰’ 검색 → 승인된 해당 단계 원문과 이동 버튼. 검색 실패 안내. 미승인 메모는 검색 대상에서 제외. 모델 호출 없음.
- [x] **I08 · 담당자의 내용 보완 연결.** 정보 부족으로 답하지 못한 질문을 작성자에게 보여준다.
  - 완료 기준: 작성자 인증 없이 질문 목록을 읽을 수 없다. 해당 안내서의 질문만 표시. 기존 승인본을 자동 수정하지 않는다.
- [x] **I09 · 로그인 전 체험 진입과 재현 자료.** 공개하기로 한 연출 사진·검토 문구로 데모를 재생성하는 명령과 명시적인 데모 진입을 제공한다.
  - 완료 기준: 빈 임시 저장소에서 API 키 없이 데모 승인본 생성·조회·사진 열기. 재실행 시 중복 생성 방지. 사용자의 기존 저장소를 덮어쓰지 않는다. AI 질문에는 별도 키 필요함을 설명한다.
- [x] **I10 · 변경 이력과 회귀 검증.** 로컬 버전 관리 시작, 비밀·state 제외 확인. 신뢰 오류·목적 분리·권한 경계 테스트, 기존 승인본 보존 확인, 브라우저 핵심 흐름 검증.
  - 완료 기준: 변경 이력·재현 명령·검증 결과 기록. 자동 검사와 실제 API·사람 평가의 범위를 구별한다.

## 구현 결정

- 추가 의미 판정 모델을 무조건 덧붙이지 않는다. 업무 규칙 답변의 생성 문장을 인용된 필드의 전체 승인 원문으로 대체해 반대 지시가 그대로 노출되는 경로부터 제거한다. 대상과 근거 연결의 정확성은 별도 평가한다.
- 사진 관찰 질문은 사용자 목적 선택을 통해 업무 규칙 질문과 구별한다. 같은 확인 대화에서 목적 변경을 허용하지 않는다.
- 디자인: 기존 파랑·흰색·황색 강조를 유지한다. 사진, 선택 대상, 질문을 작업대처럼 한 영역에 묶고 승인 설명은 바로 열 수 있게 한다. 새 UI 프레임워크와 장식 애니메이션은 추가하지 않는다.
- 최신 실제 사진·사용자·외부 배포 결과는 확보 전까지 완료로 표시하지 않는다.

## 재평가 후 수정 — 2026년 11월 2일

기준 버전: `751ba7b`. 검사 58개 통과와 구현 체크만으로 사용자 문제 해결을 판정하지 않는다. 아래 항목은 재현한 실패 흐름으로 확인한 뒤 완료 처리한다.

- [x] **R01 · 질문 모드 잔류 제거 / I03 재개방.** 빠른 사진 질문의 목적은 해당 요청에만 적용한다. 일반 입력은 질문 내용에 맞춰 처리하며 확인 대화만 기존 목적을 이어간다. 모드 때문에 규칙이 있는데 없다고 안내하지 않는다.
  - 완료 기준: 파란 펜 선택 → 빠른 색·모양 질문 → 일반 입력으로 서명 허용 질문 → 승인된 펜 규칙 응답. 목적을 고르는 부담을 기본 화면에서 제거. 과거 화면의 명시적 사진 모드로 업무 질문을 보내는 경우도 처리.
  - 수정 전 재평가: 모드 잔류 재현은 해결됐으나, ‘파란색 펜은 운영자 메모 전용인가요?’를 사진 질문으로 잘못 분류해 실제 API·브라우저에서 거절했다. 재확인 버튼은 성공. 자연스러운 용도·역할 표현까지 처리하기 전에는 전체 완료로 보지 않는다.
- [x] **R02 · 보완 질문 누락과 수명 해결 / I08 재개방.** 정상 질문 수와 무관하게 미처리 보완 질문을 조회한다. 대화의 24시간 보관과 별도로 담당자 보완 목록을 보관하고 완료·되돌리기를 제공한다.
  - 완료 기준: 보완 질문 1개 뒤 정상 질문 100개를 기록해도 남아 있음. 미처리 20개 초과·24시간 경과에도 누락 없음. 기존 정보 부족 질문 이관. 다른 안내서·비로그인 접근 차단. 완료 처리로 승인본을 바꾸지 않음.
- [x] **R03 · 대상별로 유용한 승인 답변.** 같은 설명 필드 전체를 일괄 반환하는 대신, 인용이 속한 온전한 승인 문장을 제시한다. 의미를 바꾸는 부분 인용은 확장하고 조건·예외가 감지되는 문맥에서는 전체 원문을 유지한다. 전체 승인 문맥은 항상 다시 열 수 있게 한다.
  - 완료 기준: 검은 펜과 파란 펜의 용도 질문이 각각 해당 승인 문장을 반환. 반대 지시·문장 중간 인용·중복 인용·뒤따르는 조건/예외 회귀. 의미 정확성과 모든 조건의 자동 판정을 보장한다고 표현하지 않음.
  - 수정 전 재평가: 실제 대상별 답변은 다시 통과. 통제된 검사에서는 ‘파란 펜은 운영자 메모용입니다. 참가자에게 건네지 않습니다.’의 첫 문장만 인용하면 뒤 금지 문장이 누락된다. 실제 모델 발생 사례와 구분하며, 관련 금지 문맥 보존을 보완한다.
- [x] **R04 · 모바일에서 안내를 먼저 읽기.** 사진 다음에 승인 설명·완료 확인을 두고 질문을 뒤에 배치한다. 선택 후에는 질문 위치로 바로 이동할 수 있게 유지한다.
