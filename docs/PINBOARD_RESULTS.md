# Pinboard 학습 화면 적용

2026년 11월 3일. 사용자가 새 디자인 5안 중 선택한 1번 Pinboard를 실제 학습 화면에 적용했다. [로컬 데모](http://127.0.0.1:8765/demo).

## 화면과 조작

사진을 중심에 두고 점선 보드 위에 단계별 승인 메모를 붙이는 구성이다. 사진·메모 연결선, 노란 종이, 실제 이전/다음 단계의 사진 카드를 사용한다. 주 작업 사진은 회전시키지 않아 기존 선택 좌표와 SAM 윤곽이 맞게 유지된다. 연결선은 현재 단계 메모를 함께 읽기 위한 표시이며 특정 물체에 대한 규칙의 적용 판정을 대신하지 않는다.

| 요소 | 적용 |
|---|---|
| 배경·종이 | `#f0f0ec` · `#fffefa` |
| 승인 메모 | `#f9edb7` |
| 글자·보조 글자 | `#30372e` · `#60685b` |
| 선택·연결선 | `#1859dd` |
| 로고 | Space Grotesk 600, 로컬 제공·SIL OFL 포함 |
| 본문 | 기존 한국어 시스템 글꼴, 승인 원문의 줄바꿈 유지 |

사진의 +와 사진 아래 이름 버튼은 승인된 표시 중심에서 실제 SAM 물체 선택을 요청한다. 최소 44px 선택 영역을 제공하고, 좁은 화면에서 가까운 +가 겹치면 해당 +를 숨겨 서로 분리된 이름 버튼으로 선택한다. 자유 위치 선택과 방향키·Enter·Esc 조작도 유지한다. 단계 이동·연결선 전환·완료 표시·선택 취소 후 키보드 포커스를 복구한다.

850px 이하에서는 사진·승인 메모·질문을 세로로 배치하고 연결선을 숨긴다. 질문 답변의 전체 승인 문맥은 계속 표시한다. 승인 원문 검색 결과에 설명과 완료 조건을 함께 표시해 완료 조건에서만 일치한 문구도 읽을 수 있게 했다. 검색 입력과 펼침 상태는 화면 갱신 시 유지한다.

작성자 작업 공간과 서버의 판단 로직·프롬프트·스키마는 변경하지 않았다. 별도 전역 디자인 의존성 없이 학습 화면에 범위를 한정했다. 사진과 메모를 연결하는 시각적 참고는 [tldraw](https://www.tldraw.com/)이며 원본 UI를 복사한 구현은 아니다.

## 확인 결과

자동 검사 119개(Python 108·JavaScript 11)가 통과했다. 기존 선택 좌표·키보드·마스크·검색 검사와 연결선 좌표·화면 크기 변화·잘못된 크기·모바일 선택 영역 겹침 검사를 포함한다.

```sh
python3 -m unittest discover -s tests -q
node --test tests/selection_ui.mjs tests/guide_search.mjs tests/pinboard_ui.mjs
```

실제 Chrome에서 1632px 데스크톱, 390px 및 320px 모바일을 확인했다. 가로 넘침 없이 승인 메모와 질문에 접근할 수 있었다. 모바일 펜 선택 표시는 겹치지 않고 44px 이름 버튼으로 남았다. 방향키와 Esc, 연결선 숨김/표시, 단계 선택과 사진 카드 이동, 완료 표시/해제를 확인했다. 질문 대기 중 다른 단계로 이동해도 질문과 선택 윤곽이 다른 단계로 섞이지 않았다. 작성자 홈은 원래 화면으로 열렸고 브라우저 경고·오류는 없었다.

평가용 안내서에서 ‘교육’을 검색했다. 설명에는 없는 검색어지만 완료 확인 원문의 ‘교육 이수 또는 책임자 동행’이 검색 결과에 실제 표시됐다.

## 실제 Meta 연결

호출 전 `state/evidence/pinboard/plan.json`에 대상·질문·정답·호출 한도를 정했다. 브라우저에서 실제 제품 API를 이용했으며 SAM 1회, Muse 4회로 한도를 지켰다. 질문별 별도 전체 교정 검토를 유지했다.

| 실제 입력 | 최종 결과 | 관측 서버 시간 |
|---|---|---:|
| 노란 트레이 승인 표시에서 물체 선택(x748, y475) | SAM 윤곽 표시 | 2.428초 |
| 사전등록 참가자가 왔는데 이쪽에서 명찰을 꺼내 주면 되나요? | `answered` · `blocked`, 노란 트레이의 현장등록용 규칙과 파란 트레이의 사전등록용 규칙을 함께 표시 | 20.380초 |
| 행사 시작 시간은 몇 시인가요? | `insufficient_information`, 담당자 확인 안내 | 9.090초 |

실제 호출 후 모바일 선택 버튼 겹침 처리와 포커스 복구를 추가했다. 이 변경은 표시와 조작에 한정되며 SAM 요청 좌표와 질문 API 연결은 동일하다. 최종 소스의 화면 크기 변화·키보드 조작·검색은 다시 브라우저에서 확인했다. 실제 API 2문항의 점검은 일반적인 모델 정확도 평가가 아니다. 두 질문의 보고 토큰 합계는 30,834이며 청구 금액은 조회하지 않았다.

기존 승인본 7개의 저장 문서 SHA-256은 작업 전후 모두 동일했다. 실제 질문·선택 기록은 로컬 데이터에 남으며 미해결 질문은 기존 보완 목록 정책에 따른다. 외부 배포는 이번 작업에 포함하지 않았다.

화면·API 지표·승인본 비교는 버전 관리에서 제외된 `state/evidence/pinboard/`에 보관했다. `desktop.png`, `mobile.png`, `actual-answer.png`, `actual-answers.txt`, `search.txt`, `api-results.json`, `approved-before.json`으로 확인할 수 있다. 새로고침 시 대화가 화면에서 사라지는 기존 동작은 유지한다.
