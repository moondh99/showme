# 최종 비평 후 핵심 보완 결과 — 2026년 11월 3일

기준은 [수정 전 비평](FINAL_SUBMISSION_CRITIQUE.md)의 핵심 다섯 항목이다. 사용자의 ‘이어서 진행’ 요청에 따라 제품 결함 수정과 제출 원고 준비를 진행했다. 외부 사람 검증 생략·배포 보류 결정은 유지했다. 실제 공개 저장소·영상·체험 주소가 준비되지 않았으므로 최종 제출 완료나 배포 검증 완료로 판단하지 않는다.

## 완료한 제품 수정

- 작성 화면을 다시 그릴 때 안내서·단계별로 펼친 설정, 화면 위치, 키보드 초점과 텍스트 커서 위치를 복원한다. 저장·검토 후 해당 버튼에 초점이 남으며 단계 전환 후 현재 단계 버튼에 초점을 둔다. 강조 전체 삭제로 원래 버튼이 사라지면 강조 추가 버튼으로 이동한다. 브라우저 새로고침을 넘는 편집·대화 복원은 추가하지 않았다.
- 행동 메모와 해당 메모를 사용하는 AI 생성 버튼을 같은 검토 영역에 배치했다. 일괄 생성에 필요한 메모가 비어 있으면 해당 단계의 메모로 이동한다. 메모 누락 차단 자체는 기존 기능이다.
- 질문란을 현재 사진 바로 뒤, 다른 단계 미리보기와 승인 메모보다 앞에 배치했다. 승인 메모는 상단 링크로 바로 이동할 수 있고 전체 원문을 계속 표시한다. 답변에는 선택 당시 사진과 SAM 윤곽을 함께 보여준다. 보관·한계에 관한 긴 도움말은 펼쳐 볼 수 있다.
- 승인 설명과 완료 기준 본문을 16px로 높였다. 선택·판정·인용의 구분을 유지하며 원문 조건·예외를 삭제하거나 접지 않았다.
- 실험 폴더에만 있던 샘플 사진을 저장소에 포함할 `public/demo/sample-notepad.jpg`로 복사하고 출처·원본 해시를 함께 남겼다. API와 Docker 파일 목록·빌드 허용 목록을 이 경로로 맞췄다. 따라서 실험 입력이 제외된 새 복제본에서도 샘플을 패키지에 포함할 수 있다.

## 실제 확인한 내용

원래 실행 중인 8765 서버의 안내서 대신 별도 8766 서버·임시 데이터베이스·복제 초안을 사용했다. 원래 안내서와 승인본을 편집하지 않았다.

| 확인 | 결과 |

| 강조 추가 후 전체 삭제 | 삭제된 버튼 대신 `add-box`에 초점, 저장 후 `save`로 유지 |

| 자동 검사 | Python 113개 + JavaScript 16개 = 129개 통과 |
| 소스 문법·공백 검사 | 통과 |

390×844 화면의 위치 비교는 같은 2단계 시나리오에 대한 이전 비평 기록과 이번 점검값이다. 모델의 대상 표현은 두 응답 사이에 조금 달랐으며, 통제된 사용자 실험으로 해석하지 않는다.

| 측정 | 이전 비평 | 이번 화면 |
| --- | ---: | ---: |
| 작업 사진 상단 | 약 524px | 약 453px |
| 선택 후 질문 제목 | 약 1,507px | 약 770px |
| 선택 전 질문 제목 | 별도 기록 없음 | 약 871px |
| 답변 카드 높이 | 약 991px | 약 835px |

질문 동선은 짧아졌지만 답변 하나가 여전히 화면 한 장에 가깝고, 모델을 14~20초 기다렸다. 사용성 완성이나 응답 시간 보장을 주장하지 않는다. 질문 결과의 승인 설명 원문이 데모 안내서의 전체 문장과 같은 것을 확인했다. 최종 학습 화면에서 브라우저 콘솔 오류는 확인되지 않았다.

자동 시각 탐지기는 기존 CSS의 굵은 한쪽 테두리 선언 5건을 보고했다. 실제 표시와 덮어쓴 선언을 구별해 모두 1px로 정리했다. 한 번 실행한 탐지기 자체를 재실행하거나 새 점수를 산출하지 않았다. 전체 접근성 인증·전체 색 대비 전수 검사로 표현하지 않는다.

## 제출 자료

[3분 시연 대본](DEMO_RUNBOOK.md)을 물체 선택 → 용도 확인 → 잘못된 규칙 적용 금지 → 정보 부족 유보 → 작성·승인·기존 승인본 보존 순서로 교체했다. 실제 대기를 잘라내면 표시하고, 결과를 대본으로 대체하지 않도록 했다.

[제출 자료 초안](SUBMISSION_PACKET.md)은 실제 공식 제출 폼의 Project Description, Meta 제품 활용, 모델의 중요성에 맞춘 영문 원고를 담는다. 공개 GitHub, 접근 가능한 3분 영상, 기여자·신규 구현 범위, 직접 선택할 설문·홍보 동의를 별도 남은 항목으로 기록했다. 폼을 제출하거나 동의하지 않았다.

## 남은 한계·다음 단계

1. 공개 저장소 계정·주소와 외부 호스팅 대상이 아직 정해지지 않았다. 공개 저장소 생성·코드 게시·외부 배포는 하지 않았다.
2. 영상은 대본 단계이며 실제 녹화·편집·업로드가 남는다.
3. Docker 엔진이 꺼져 실제 이미지 빌드·컨테이너 실행은 하지 못했다. Dockerfile의 COPY 파일로 배포 트리를 재현해 API를 확인했다. 새 복제본 실행과 외부 HTTPS·영속 디스크 재시작 검증은 별도다.
4. 화면 크기 모의 점검이며 실물 iPhone/Android 터치·소프트 키보드·전체 스크린리더는 미검증이다. 실제 외부 사람 검증은 이번 제출 필수 조건에서 제외한다.
5. 대화 새로고침 복원·작성자/학습자 브랜드 통일·공개 연구 페이지 정리는 이번 핵심 수정에서 확장하지 않았다.
