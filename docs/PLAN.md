# ShowMe 개발 계획

2026년 11월 1일 핵심 기능 기획을 구체화했습니다. 제품 동작과 범위의 기준은 [제품 기획](PRODUCT_SPEC.md), 데이터·요청 계약·작업 순서의 기준은 [구현 계획](IMPLEMENTATION_PLAN.md)입니다. 이 문서는 일정과 진행 상태를 요약합니다.

같은 날 사진 한 장의 흐름에 이어 최대 6단계 순서 편집·검토·전체 승인·학습을 실제 구현·검증했습니다. [다단계 결과](MULTISTEP_RESULTS.md)와 [실행 안내](LOCAL_RUN.md)를 참고하세요. 이어 현재 단계 사진·승인 설명을 근거로 한 질의응답과 확인 대화도 [구현·검증](QUESTIONS_RESULTS.md)했습니다.

## 제품 범위

숙련자가 사진 4~6장과 순서·메모를 등록하면 작업 안내서 초안을 생성합니다. 숙련자가 설명과 강조 위치를 검토한 뒤 승인하고, 초보자는 안내서를 따라 하며 사진과 연결된 질문을 할 수 있습니다.

첫 제품 시나리오는 행사 접수대 준비로 기획합니다. 공개 사진 3장을 통한 단일 사진 API 검증은 끝났으며, 실제 준비 과정을 보여줄 연속 사진과 사용자 테스트 참여자는 추가 확보해야 합니다. 1단계 전체 흐름부터 구현한 뒤 최대 6단계로 확장합니다.

첫 버전의 질문은 현재 단계의 사진과 승인된 설명에 한정합니다. 전 단계 자동 검색과 사진에서 누른 영역을 해석하는 질문은 추가 검증이 필요한 P1입니다. 승인본은 초안과 분리해 저장하고, 수정 중인 초안이 기존 학습 링크를 바꾸지 않게 합니다.

## 개발 순서와 완료 조건

### 1. Meta 이미지 API 검증

- 실제 사진에서 물체 설명과 질문 답변을 받습니다.
- 질문에 해당하는 물체 위치를 반환받아 원본 사진 위에 표시합니다.
- 대상이 없거나 질문이 모호한 경우의 응답을 확인합니다.
- 실행 결과와 사람이 판정한 결과를 기록합니다.

검증 절차와 제안된 통과 기준은 [실험 안내](../experiments/meta-vision/README.md)에 정리합니다. 이 단계의 결과로 기능 범위를 정합니다.

### 2. 안내서 생성과 검토

- 사진 업로드, 순서 지정, 단계별 메모 입력
- 사진과 메모를 바탕으로 단계 제목·행동·완료 확인 항목 생성
- 설명·근거 사진·강조 위치 수정과 승인

완료 조건: 담당자가 실제 자료로 안내서 하나를 생성·수정·승인하고 다시 열 수 있습니다. 사진만으로 알 수 없는 업무 규칙은 입력 메모를 근거로 작성합니다.

### 3. 따라 하기와 사진 질문

- 휴대전화 화면에서 단계별 사진·설명·강조 영역 표시
- 이전·다음·완료 표시
- 질문에 대한 답변과 근거 사진·단계 연결
- 현재 단계의 사진·승인된 설명에 질문하고, 모호한 대상에는 추가 확인
- 승인본 읽기 전용 학습 링크와 같은 기기의 학습 진행 복원
- 자료에 없는 내용과 모호한 대상에 대한 추가 확인

완료 조건: 초보자가 안내서를 보며 작업을 마치고, 질문에서 관련 사진과 대상 위치를 확인합니다. 단계 완료 표시는 사용자가 직접 합니다.

사진 영역 선택 질문·여러 단계 검색은 P1이며 위 완료 조건에 포함하지 않습니다.

### 4. 사용자 검증과 제출

- 가능하면 2~3명에게 실제 작업을 수행하도록 요청
- 누락 단계, 추가 질문, 작업 시간 기록
- 잘못된 답변·강조 위치와 수정 결과 기록
- 배포, 데모 영상, 프로젝트 설명, 제출 완료 확인

## Meta AI 활용

Muse Spark를 사진·메모 이해, 질문 대상과 근거 단계 선택, 위치 좌표 출력에 사용합니다. 앱에서는 사진·단계 식별자와 좌표 범위를 검사하고 위치를 표시합니다. 좌표가 유효하다는 사실만으로 대상이 정확하다고 판단하지 않습니다.

SAM 3.1을 통한 물체 윤곽 표시는 추가 기능입니다. 실제 계정 접근과 정확도를 확인한 뒤 포함 여부를 정합니다. 작업 완료 자동 판정, 실시간 영상 분석, 음성 입력은 첫 버전 범위에 포함하지 않습니다.

2026년 11월 1일 사용자 계정에서 Muse Spark 1.3 이미지 호출을 검증했습니다. 공개 실제 사진 3장과 질문 10개에서 물체 위치·대상 없음·추가 확인 응답을 확인했습니다. [결과](../experiments/meta-vision/RESULTS.md)를 근거로 사각형 강조와 담당자 위치 보정을 우선 구현합니다. SAM과 작업 완료 자동 판정은 계속 후순위로 둡니다.

- [Meta 이미지 입력 예제](https://dev.meta.ai/docs/cookbook/vision-input)
