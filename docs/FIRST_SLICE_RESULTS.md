# ShowMe 사진 한 장 전체 흐름 검증

2026년 11월 1일, 로컬 앱에서 **사진 업로드 → 실제 Meta 초안 생성 → 설명·위치 수정 → 검토 → 승인본 저장 → 학습 화면 조회**를 확인했습니다. 검증 시나리오는 ‘서명 도구 준비 안내’입니다. 다단계·학습자 질문·외부 배포는 이번 구현 범위에 포함하지 않았습니다.

## 실제 사용한 자료와 모델

- 사진: 기존 검증에 사용한 실제 노트북·노트·검은 펜 사진. [Eric Bailey / Wikimedia Commons / CC0](https://commons.wikimedia.org/wiki/File:Laptop_picture_with_notepad.jpg).
- 담당자 메모: ‘검은 펜을 격자 노트 위에 놓습니다. 펜은 참가자 서명용입니다. 펜과 노트가 함께 준비되어 있는지 확인합니다.’
- 모델: `muse-spark-1.3`.
- 이번 앱 생성 경로에서 실제 호출 1건, 응답 5.907초, 입력 2,125토큰·출력 1,419토큰·합계 3,544토큰. 앞선 물체 위치 실험 10건과 별도입니다.
- 모델 응답 구조는 단계 제목·할 일·완료 확인·강조 영역·확인할 내용으로 확장했으며 실제 호출이 성공했습니다.

모델은 ‘서명용 펜과 노트 준비’라는 제목과 담당자 메모에 근거한 설명을 생성하고 펜·노트의 위치를 반환했습니다. 반환된 상자는 편집 가능한 후보로 취급했습니다.

## 전체 흐름 확인

| 구간 | 확인 내용 | 근거 |
| --- | --- | --- |
| 화면 → 사진 등록 | 브라우저 파일 선택기로 실제 JPEG 업로드 | 작업 사진 표시, 서버의 정규화 사진 저장 |
| 화면 → 입력 저장 → Meta API | 제목·목표·메모 입력 후 생성 | 저장된 입력과 실제 모델·응답 시간·사용량 |
| 응답 → 편집 화면 | 단계 제목·설명·완료 확인·펜과 노트 상자 표시 | 생성 완료 화면과 저장된 초안 |
| 편집 → 저장 | 설명을 다듬고 펜 상자를 `[508,535,882,704]`로 수정 | 저장한 설명과 `origin=author` 좌표 |
| 검토 → 승인 | 단계 검토 완료 후 승인본 생성 | 승인본 1과 별도 읽기 전용 링크 |
| 승인 → 조회 | 학습 화면에서 수정한 설명과 보정한 위치 확인 | 브라우저 승인본 화면 |
| 초안 변경 → 기존 승인본 | 임시 초안 변경, 검토 해제, 기존 승인본 유지 | 실제 HTTP 검사 후 원래 초안 복원 |
| 재시작 → 데이터 유지 | 서버 종료·재실행 후 승인본·사진·작성자 목록 복원 | 실제 서버 재시작 및 브라우저 새로고침 |
| 모바일 → 진행 복원 | 390×844 화면에서 가로 넘침 없음, 완료 표시 새로고침 후 유지 | 모바일 화면과 DOM 크기 확인 |

브라우저 콘솔에 오류·경고가 없음을 확인했습니다. 학습 진행은 브라우저에 저장하며 서버가 작업 완료를 자동 판정한 것은 아닙니다. 테스트 중 ‘검토 완료’와 ‘승인’은 Codex가 동작 확인을 위해 수행했으며 독립적인 실제 사용자 검수와 구분합니다.

## 실제 서버의 보호 규칙 확인

- 로그인 없는 초안 조회와 비공개 사진 요청: HTTP 401.
- 로그인 없는 승인본 내용·해당 승인 사진 요청: HTTP 200.
- 승인본에는 미승인 담당자 메모와 모델 사용량을 반환하지 않음.
- 초안을 변경하면 검토 표시 해제, 미검토 상태의 승인 요청: HTTP 422.
- 오래된 version으로 저장: HTTP 409, 현재 초안 유지.
- 승인 후 초안 내용 변경에도 기존 승인본 내용 유지. 검증 뒤 초안은 원래 내용으로 복원하고 다시 검토 처리.

## 자동 테스트와 구현

자동 테스트 15개가 통과했습니다. 기존 사진 검증 도구 테스트 8개와 앱 통합 테스트 7개입니다. 앱 통합 테스트는 파일 내용 검사·좌표 검사·다른 출처 요청 거절·미인증 접근·승인본 고정·검토 상태·저장 충돌·생성 도중 수정·실패 시 보존·재시작 후 저장을 확인합니다. 가짜 모델 응답을 사용하므로 위 실제 호출 1건과 구분합니다. 브라우저 코드 구문 검사도 통과했습니다.

FastAPI, SQLite, 기본 HTML/CSS/JavaScript로 구현했습니다. 기존 실험과 앱은 `src/showme/images.py`의 전처리·좌표 검사 코드를 공유합니다. 원래의 실험 실행 경로와 기록은 유지했습니다.

실제 로컬 검증 기록은 `state/evidence/first-implementation.json`, 화면은 `state/evidence/approved-guide.png`, `state/evidence/mobile-approved-guide.png`에 보관합니다. 키와 이미지 base64는 검증 로그에 보관하지 않습니다. 상태 폴더는 버전 관리에서 제외합니다.
