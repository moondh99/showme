## R10·R11 판단 유지

두 방식 모두 목적/상태 **28/28**, 대상/적용 판정 **17/17**, 실제 필수 인용 그룹 **17/17**, 금지·조건부의 잘못된 허용 **0/12**였다. 선택 반복도 대상·금지 판단 **3/3**이었다. 전체 인용 coverage에는 인용이 필요 없는 사진/미해결 질문이 포함되므로 필수 인용 분모를 별도로 보고한다.

업무 명칭이 있는 외형 질문, AND/OR 대조, 미확인 나이/반납, 다른 필드의 조건, 선택 대상에 다른 권한을 옮기는 요청, 없는 규칙을 최종 서비스 응답에서 내부 검토했다. 조건 인용은 모두 승인 필드의 실제 문구였다. 금지 조항의 met/not_met 표현은 형식 논리 원자 명제의 증명으로 해석하지 않는다. 최종 대상·판정·적용 원문을 함께 확인했다. 세트의 별칭/문자열 채점만으로 일반적인 의미 정확성을 입증하지 않는다.

자동 검사 **113개(Python 108·JavaScript 5)**가 통과했다. 추론 설정의 실제 HTTP 전달, 구간별 지표, 제품 최대 2회와 별도 교정 유지, 기존 비교 요청의 깊이 생략, 공개 정책 주입 차단, 불완전 출력의 오류 처리, 기존 인용/조건 제한·실패 시 답변 유보를 포함한다. 폐기한 작은 검토/세 번째 교정 경로는 명시적 내부 비교 설정으로 검사한다.

## 판정과 남은 범위

사전 고정 회귀 품질과 지연 기준은 모두 통과했다. 관측한 긴 대기의 주된 개선점은 명시적 추론 깊이 조절과 세 번째 교정 왕복 제거다. 공급자 내부 대기/처리의 정확한 분해나 향후 최대 응답 시간은 알 수 없다. 이번 최대 2회는 호출 수 상한이며 시간 상한이 아니다.

R12의 호출·긴 대기 **기술 개선은 이 내부 검증 범위에서 완료**했다. 실제 사람이 20초대 답변을 기다릴 수 있는지, 새 사진/새 규칙에서의 품질은 미검증이다. 체크리스트의 실제 사용자 수용성 항목은 열어 둔다. 일반 정확도 100%, 새 블라인드 검증, 현장 효과, 전체 제품/제출 완료로 표현하지 않는다.

이번 실제 호출은 **Muse 139회·SAM 1회**다. 첫 진단 canary 13회(폐기 조합 포함), 전체 교정 canary 6회, 고정 28개+선택 반복 3쌍 비교 115회, 제품 브라우저 5회다. 기존 설정의 세 번째 교정도 포함한다. 자동 검사 수·질문 수·모델 호출 수를 구별한다. 청구 금액/잔액은 조회하지 않았다.
